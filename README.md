# 🚀 InfraSense AI

InfraSense AI is an AI-powered Smart City Infrastructure Monitoring platform that enables citizens to report public infrastructure issues using images. The system automatically detects the issue using Google's Gemini AI, classifies its severity, identifies the responsible government department, and provides recommended actions.

## 🌐 Live Demo

**Live Application:** https://infrasense-ai.onrender.com

## ✨ Features

* AI-powered infrastructure issue detection
* Image upload and analysis
* Automatic severity classification
* Department recommendation
* Smart AI-generated summary
* Recommended corrective actions
* Interactive analytics dashboard
* Infrastructure hotspot insights

* Category-wise report analysis

## 🤖 AI Workflow

1. User uploads an infrastructure image.
2. Gemini AI analyzes the image.
3. Issue category is detected.
4. Severity level is assigned.
5. Responsible department is identified.
6. Recommended action is generated.
7. Report is stored in the database.
8. Dashboard updates automatically.
